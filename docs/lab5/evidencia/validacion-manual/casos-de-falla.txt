## A. El archivo de salida no se puede escribir (Ollama activo)
$ bash validar-ollama.sh /carpeta-que-no-existe/salida.txt
docs/lab5/evidencia/validacion-manual/validar-ollama.sh: line 16: /carpeta-que-no-existe/salida.txt: No such file or directory
FALLA: no se puede escribir el archivo de salida: /carpeta-que-no-existe/salida.txt
(codigo de salida: 1)

$ bash variante-encabezado.sh salida.txt

(codigo de salida: 1)
=> esperado: 200 con 'Access-Control-Allow-Origin: http://otro.local' | obtenido: 200 sin 'Access-Control-Allow-Origin: http://otro.local' (curl: 0) | FALLA
